# Ephemeron

> **Status: scaffold only.** The idea below is the plan, not what the code does yet — the package currently contains no implementation. Watch the repo if you want to know when it does something.


One command starts a throwaway container with your chosen toolchain and a temporary SSH endpoint, and destroys it when the last session disconnects. For testing scripts or giving contractors short-lived access.
